# 슬롯 하이에나 Android

- **기종 데이터 확충**: 현재 총 28개 주요 기종의 천장 및 판정 기준 데이터 탑재
- **전략적 판정**: 직접 AT / 보너스 유지 기종을 구분하여 HIGH(강력 추천) / MID(추천) / LOW(진입 불가) 3단계 판정
- **실시간 계산기**: 현재 게임수 입력 시 남은 게임수와 기대치 구간 자동 계산
- **홀 정보 연동**: 후쿠오카(오노죠/하카타 인근) 8개 주요 홀의 P-WORLD 및 구글 지도 연동
- **로컬 저장**: SharedPreferences를 이용한 기종 데이터 관리

## 🎰 탑재 기종 및 판정 기준
1. **대상**: 직접 AT 확정 천장이 있거나, 보너스 후 AT 돌입 확률이 높은 기종 위주
2. **제외(PASS)**: CZ만 확정되거나 AT 천장이 1200G를 초과하여 효율이 낮은 경우
3. **단위 지원**: 게임수(G) 외에 포인트(pt) 단위 기종(철권6 등) 대응
